## HR Reply Scripts v2.0 — 求职者回复 HR 话术库

**核心定位**：中文优先的求职沟通话术与技巧库。

**价值亮点**

- 覆盖 **20+ 真实场景**：谈薪（含当前薪资重定向、总包拆解、绩效系数陷阱）、催面试进度、接受 / 拒绝 / 暂缓 Offer、多 Offer 管理、口头 Offer 条款核对、已读不回突围、空窗期 / 离职原因解释（含大厂毕业脱敏）、猎头沟通、反诈拒坑等。
- 输出「模板 + 成品示例 + 雷区备注」三件套，信息齐全时直接填入成品可照抄。
- 谈薪场景强制给【温柔版 / 专业版 / 锋芒版】三档，并先「侧写 HR 心理状态」再选版本。
- 含 AI 异步视频面试、反向背调、脉脉 / 小红书避雷核验等新型场景。

> 一句话：把每一次和 HR 的对话，都变成有策略、有底线的沟通。
