# HR 回复话术库 · 完整脚本（求职者视角）

> 用法：每个场景含【模板（带占位符）】+【成品示例】+【备注（为什么/雷区）】。
> 第 4 类"谈薪"额外给【温柔版 / 专业版 / 锋芒版】三档。

---

## 1. 首轮沟通破冰（主动联系 HR / 投递后跟进）

**触发**：投了简历想主动引起 HR 注意；Boss / 邮件初次沟通。
**核心**：30 秒讲清"我是谁 + 为什么匹配 + 有什么证据"。

### 模板 A（标准版）
```
HR您好！我是[姓名]，对贵司发布的[岗位名称]很感兴趣。
我曾在[公司/项目]负责[核心职责]，产出了[数据成果，如"用户增长30%"]，
熟练使用[技能/工具，如数据分析/用户运营]，与岗位JD匹配度较高。
附件为简历[及作品集]，期待与您进一步沟通！
```

### 成品示例 A
HR您好！我是李明，对贵司发布的"用户增长运营"岗位很感兴趣。我曾在某电商平台负责私域用户运营，半年内将会员复购率从 18% 提升至 27%，熟练使用 SQL 与企微 SCRM，与岗位 JD 匹配度较高。附件为简历及作品集，期待与您进一步沟通！

### 模板 B（招聘软件 / 未发简历版）
```
您好，看了贵公司的岗位JD，对贵司发布的[岗位名称]很感兴趣。
我有[年限]年的[领域]经验，具备[核心能力]，擅长[亮点]，有[具体成果]的经验
（这部分可以套用岗位JD里的关键词）。与贵公司的岗位匹配度较高，
如果您觉得合适，可以回复一下，我给您发我的简历和作品集，谢谢！
```

### 成品示例 B
您好，看了贵公司的岗位 JD，对贵司发布的"新媒体运营"很感兴趣。我有 3 年的内容运营经验，具备爆款选题与数据分析能力，擅长短视频脚本与账号从 0 到 1 冷启动，有单月涨粉 5 万 + 的操盘经验。与贵公司的岗位匹配度较高，如果您觉得合适，可以回复一下，我给您发我的简历和作品集，谢谢！

### 模板 C（2026 职场风 · 有态度有边界）
```
[姓名]-[核心标签]-申请[岗位]。附件简历中与 JD 的匹配点已用高亮标出（如：[XX 行业用户增长经验]、[XX 证书]）。如有疑问随时沟通；若 3 天内无回复，我将默认该岗位已满，转做其他安排。
```
- 成品：
张明-3年SaaS增长-申请用户增长运营。附件简历中与 JD 的匹配点已用高亮标出（如：从 0 到 1 搭私域、复购率 18%→27%）。如有疑问随时沟通；若 3 天内无回复，我将默认该岗位已满，转做其他安排。

### 备注
- 首句直接上"兴趣 + 岗位"，别寒暄"在吗"。
- 用数字证明匹配，别堆形容词；简历未发时先抛"钩子"，用 JD 关键词证明自己匹配。
- **2026 基调（平等协作，不卑不亢）**：避免"求求您看一眼""知道您很忙打扰了"式讨好。把姿态放平——你是来展示价值的，不是乞求机会。模板 C 的"3 天内无回复默认已满"是**有边界**的表达，降低对方心理负担，反而提升回复率（HR 知道你有其他安排，不会无限拖延你）。
- **雷区**：长篇自我介绍、群发同款无差别文案；过度卑微显得没底气；"跪舔式"在 2026 招聘市场已失效，HR 对模板化讨好有免疫力。

## 2. 已读未回突围

**触发**：HR 已读不回 / 投递后石沉大海。
**核心**：给台阶 + 留退路，不卑不亢；不同阶段问法不同。

### 分支 A：未发简历 / 刚打招呼后已读不回
- 模板：
```
您好，这边显示您已经读过我的消息，暂时没有收到回复，想问一下是否有什么顾虑呢？
我对此岗位很感兴趣，如果有需要，我可以提供更详细的信息供您了解。
如果不合适，还辛苦告知一声，谢谢！
```
- 成品：
您好，这边显示您已经读过我的消息，暂时没有收到回复，想问一下是否有什么顾虑呢？我对此岗位很感兴趣，如果有需要，我可以提供更详细的信息供您了解。如果不合适，还辛苦告知一声，谢谢！

### 分支 B：已发简历后已读不回
- 模板：
```
您好，我是[姓名]，之前在[平台]向贵公司投递了[岗位]的简历。
我注意到您已读了我的消息，但我还没有收到任何回复。
我想确认一下我的简历是否还在考虑之列，或者是否需要提供更多信息。期待您的回复。
```
- 成品：
您好，我是张华，之前在 Boss 直聘向贵公司投递了"产品经理"的简历。我注意到您已读了我的消息，但我还没有收到任何回复。我想确认一下我的简历是否还在考虑之列，或者是否需要提供更详细的作品集。期待您的回复。

### 分支 C：已读不回 + 主动出击（自荐式强推）

- **适用**：你确实非常想要这个岗位；HR 已读不回超过 2–3 天、且前两次温和跟进（分支 A/B）无果。此时不再只"问顾虑/问进度"，而是借机把**求职动机 + 岗位匹配 + 自身能力**一次性讲清，把一条被忽略的消息变成一份微型自荐信。
- **结构（三段式，缺一不可）**：
  1. **求职动机**：为什么是**这家公司/这个岗位**（而非泛泛"感兴趣"），证明这是定向投递而非海投。
  2. **与岗位匹配程度**：逐条对应 JD 关键词，点明岗位要求的重点能力你正好具备。
  3. **自身工作能力**：用**一项带数字的硬成果**证明，说明可立即上手岗位核心任务。
- **模板**：
```
[称呼]您好，看到消息已被读取但还没收到回复，我猜您可能比较忙、或对我的背景有疑问。
借这个机会，我简单说明一下为什么我很坚定想加入[公司]做[岗位]：
一、求职动机：我长期关注[公司业务/产品]，尤其认同[某点]，
个人职业规划也正好落在[方向]，所以这不是海投，是定向投递。
二、匹配程度：对照 JD，我在[能力1]、[能力2]、[能力3]上都有直接对应经验，
其中[能力2]正是岗位要求的重点。
三、工作能力：在[上家公司/项目]我负责[职责]，产出[量化成果，如"降本20%/从0搭起XX体系"]，
可立即上手[岗位核心任务]。
如需进一步了解，我可随时提供更完整的简历与作品集。期待有机会和您沟通，谢谢！
```
- **成品示例**：
王经理您好，看到消息已被读取但还没收到回复，我猜您可能比较忙、或对我的背景有疑问。借这个机会，我简单说明一下为什么我很坚定想加入贵司做"用户增长运营"：一、求职动机：我长期关注贵司的私域打法，尤其认同"以内容驱动复购"的思路，个人职业规划也正好落在用户增长方向，所以这不是海投，是定向投递。二、匹配程度：对照 JD，我在私域运营、数据分析（SQL）、活动策划上都有直接对应经验，其中私域运营正是岗位要求的重点。三、工作能力：在上家公司我负责会员体系搭建，半年将会员复购率从 18% 提升到 27%，可立即上手贵司的复购增长项目。如需进一步了解，我可随时提供更完整的简历与作品集。期待有机会和您沟通，谢谢！

### 分支 D：试探性撤退（怀疑岗位暂停 / HC 冻结）
- **适用**：已读不回且你不确定原因，强推怕踩雷；或你已感知对方可能"岗位有变 / HC 暂缓"。与其继续强推制造尴尬，不如体面留余地，把主动权交还 HR，反而留个好印象。
- 模板：
```
[称呼]您好，之前和您沟通过[岗位]，看到消息已读但暂无回复。
我有个猜测：是不是这个岗位目前 HC 暂缓、或方向上有些调整？
如果只是时机问题，我完全理解，暂不打扰您；若岗位仍开放，
我也很乐意补充任何材料。无论哪种，都感谢您之前的关注！
```
- 成品示例：
李经理您好，之前和您沟通过"用户增长运营"，看到消息已读但暂无回复。我有个猜测：是不是这个岗位目前 HC 暂缓、或方向上有些调整？如果只是时机问题，我完全理解，暂不打扰您；若岗位仍开放，我也很乐意补充任何材料。无论哪种，都感谢您之前的关注！

### 备注
- 把"求回复"换成"以便我调整规划"或"是否还在考虑之列"，给对方合理拒绝的理由，反而更容易得到回应。
- 未发简历问"是否有顾虑"；已发简历问"是否还在考虑"——阶段不同，问题不同（分支 A/B）。
- **分支 C 适用边界**：真想要 + 已读 2–3 天 + 温和跟进无效。别在**第一条**消息就用强推，会显得用力过猛、像群发硬广。
- 主动出击时严格按"动机 → 匹配 → 能力"三段式，用**数字**和 **JD 关键词**背书，避免空泛表白"我很优秀"。
- **分支 D 适用边界**：不确定对方为何已读不回、或怀疑岗位暂停时。把"是否 HC 暂缓"说出口，既给对方台阶，也避免你在错误目标上死磕。
- **2026 基调**：已读不回消息也别卑微。分支 C 的强推是"平等展示"，不是"求回复"；分支 D 的撤退是"体面留余地"，不是"认怂"。全程用"我理解 / 我调整规划"替代"求您 / 麻烦您"，姿态更稳。
- **雷区**：连续追问、质问"为什么不回我"；或强推时编造不匹配的经历/成果（入职前会被验证，直接出局）。

## 3. 面试后跟进 / 催结果

**触发**：面试完想问进度，怕显得急 / 掉价；或到了约定时间没收到通知。
**核心**：问"流程"而非"过没过"；给明确时间节点；未通过也可礼貌求反馈。

### 模板 A（通用版 / 面试后 2–3 天）
```
[称呼]您好，我是[日期]面试[岗位]的[姓名]。
非常有幸能和您沟通，想问下目前流程大概走到哪一步了？
因为我这边也在规划接下来的面试安排，很心仪贵司，所以想优先确认一下进度，谢谢！
```

### 成品示例 A
王经理您好，我是周三面试"产品经理"的张华。非常有幸能和您沟通，想问下目前流程大概走到哪一步了？因为我这边也在规划接下来的面试安排，很心仪贵司，所以想优先确认一下进度，谢谢！

### 分支 B：刚面试完 / 面试中问结果时间
- 模板：
```
[称呼]您好，我想问一下今天的面试结果大概什么时候出来呢？
```
- 成品：
王经理您好，我想问一下今天的面试结果大概什么时候出来呢？

### 分支 C：到约定时间没收到通知（一般情况）
- 模板：
```
[称呼]您好，我于[日期]与您进行了[岗位]的面试，非常感谢您给予的面试机会。
之前说会在[天数]天内通知面试结果 / 距离面试过去[时间]了，
想了解一下面试结果出来了吗？期待您的回复，打扰了。
```
- 成品：
王经理您好，我于上周三与您进行了"高级运营"的面试，非常感谢您给予的面试机会。之前说会在 3 天内通知面试结果，想了解一下面试结果出来了吗？期待您的回复，打扰了。

### 分支 D：到约定时间没收到 + 想尽快决策（手握其他 offer）
- 模板：
```
[称呼]您好，我于[日期]与您进行了[岗位]的面试，非常感谢您给予的面试机会。
我目前收到了其他公司的 offer，他们希望我尽快回复，不过我很想加入贵公司，
想了解一下面试结果出来了吗？期待您的回复，打扰了。
```
- 成品：
王经理您好，我于上周三与您进行了"高级运营"的面试，非常感谢您给予的面试机会。我目前收到了其他公司的 offer，他们希望我尽快回复，不过我很想加入贵公司，想了解一下面试结果出来了吗？期待您的回复，打扰了。

### 分支 E：得知面试未通过，礼貌求反馈
- 模板：
```
[称呼]您好，谢谢您的反馈。我非常感谢能有这次面试的机会，并与您及[公司]的团队有所交流。
如果可能的话，您能否提供一些关于我面试表现的反馈？
我真心希望了解在哪些方面我可以做得更好，无论是技能、经验还是面试技巧，我都非常愿意倾听并学习。
再次感谢您！
```
- 成品：
王经理您好，谢谢您的反馈。我非常感谢能有这次面试的机会，并与您及某某科技的团队有所交流。如果可能的话，您能否提供一些关于我面试表现的反馈？我真心希望了解在哪些方面我可以做得更好，无论是技能、经验还是面试技巧，我都非常愿意倾听并学习。再次感谢您！

### 备注
- "想问流程走到哪一步"给 HR 缓冲，比"我过了吗"得体。
- "我在规划接下来的安排"潜台词：我很抢手，但优先考虑你们——拉高身价。
- **轮次耐受度不同（重要）**：初试后催最招烦——HR 还在海选，你急显得 desperation，能忍则忍、用分支 A 轻问即可；HR 面 / 终面后催，HR 反而觉得你重视、意向强，可以更大方直接问。催的语气与频率随轮次调整：越往后越可明问，越早越要克制。
- **时机**：面试后 2–3 天，或承诺反馈时间的次日上午 10:30。
- **雷区**：一天内多次催；用"在吗"开场；未通过时质问或纠缠。

## 4. 谈薪（核心场景 · 多版本）

**触发**：HR 问期望薪资 / 给你 offer 想谈高 / 被压价 / 对拟定薪资不满意。
**核心**：先探后报，用区间而非死数；以市场 + 价值为依据；不情绪化；用整体包视角。

### 4.0 谈薪前先"侧写"HR（输出话术前必读）
HR 压价时通常处于三种心理状态之一，破局点不同：
1. **内部有更便宜的备选** → 破局：用"稀缺性 + 可立即产出"证明你更省隐性成本（招聘周期、培训成本）。
2. **你的期望超出职级带宽上限** → 破局：先探带宽（"请问这个岗位的职级带宽上限大概是多少？"），再谈；若真超了，转谈签字费 / 试用期后调薪 / 非现金补偿。
3. **试探你的底线弹性** → 破局：守住区间下限不松口，用市场分位 + 业绩背书，不轻易用"我再想想"式让步。

> 输出谈薪话术前，先判断 HR 大概率属于哪一类，再选用 4.1–4.3 的对应版本。

### 4.1 HR 首次询问"你期望薪资多少"——先反探再给区间

**温柔版（应届 / 求稳）**
- 模板：
```
感谢您的提问。在给出具体数字前，想先了解这个岗位的薪资结构和带宽范围，
以及除 base 外的绩效/年终/补贴构成。结合我的[学历/实习/项目]背景，
期望月薪在[区间下限]–[区间上限]之间，当然也看整体包和成长空间。
```
- 成品：
感谢您的提问。在给出具体数字前，想先了解这个岗位的薪资结构和带宽范围，以及除 base 外的绩效、年终、补贴构成。结合我的硕士背景与两段相关实习，期望月薪在 12k–15k 之间，当然也看整体包和成长空间。

**专业版（有经验 / 主流推荐）**
- 模板：
```
基于我对[城市/行业]同岗位的市场了解，以及我在[相关经验/量化成果]上的积累，
我的期望年薪总价（含绩效年终）在[下限]–[上限]万。
这个数字对应[级别/能力]，我相信能为团队带来[价值点]。具体可结合贵司薪酬体系再谈。
```
- 成品：
基于我对上海互联网同岗位的市场了解，以及我在 3 年 SaaS 增长上的量化积累（主导过 2 次破百万的裂变），我的期望年薪总价（含绩效年终）在 35–42 万。这个数字对应中高级执行能力，我相信能为团队带来可复制的增长方法论。具体可结合贵司薪酬体系再谈。

**锋芒版（手握其他 offer / 稀缺岗）**
- 模板：
```
我的预期很清晰：年薪总价在[下限]–[上限]万（base[数字]k×[月数]+绩效），这是我的市场对标区间。
目前我也收到[同级/竞品]的[数字]万包，但更看好贵司的[业务/平台]，
所以优先和您对齐。如果预算能匹配，我们可以很快推进。
```
- 成品：
我的预期很清晰：年薪总价在 38–45 万（base 28k×15 + 绩效），这是我的市场对标区间。目前我也收到竞品的 38 万包，但更看好贵司的国际化业务，所以优先和您对齐。如果预算能匹配，我们可以很快推进。

### 4.2 被压价时的回应（守住底线）
- 模板：
```
理解贵司的预算框架。不过结合我的[稀缺技能/可直接产出]，
我认为[原数字]更贴近市场与我的贡献。能否在[签字费/早鸟bonus/试用期后调薪]上做些补足？
如果暂时做不到，我也理解，希望能保持联系。
```
- 成品：
理解贵司的预算框架。不过结合我在出海投放上的直接操盘经验（曾把 CAC 压到行业均值的 60%），我认为年薪 38 万更贴近市场与我的贡献。能否在签字费或试用期后调薪上做些补足？如果暂时做不到，我也理解，希望能保持联系。

### 4.3 对拟定 offer 薪资不满意（三回合谈判）

**第一回合：明确提出期望**
- 模板：
```
我理解您所提出的薪资水平，并感谢您对我的考虑。
根据我的市场调研和个人能力，我认为我可以为公司带来的价值可能超出了这个薪资范围。
我希望我的薪资能达到[期望数字]，您看您这边能否再为我争取一下？
```
- 成品：
我理解您所提出的薪资水平，并感谢您对我的考虑。根据我的市场调研和个人能力，我认为我可以为公司带来的价值可能超出了这个薪资范围。我希望我的薪资能达到年薪 32 万，您看您这边能否再为我争取一下？

**第二回合：争取非现金补偿或了解涨薪机制**
- 模板：
```
如果目前的薪资水平难以调整，我们能否讨论其他形式的补偿，
比如更灵活的工作安排、额外的培训机会或者长期的职业发展路径？
或者方便了解一下公司目前的涨薪机制和年终奖是怎样的吗？
```
- 成品：
如果目前的薪资水平难以调整，我们能否讨论其他形式的补偿，比如更灵活的工作安排、额外的培训机会或者长期的职业发展路径？或者方便了解一下公司目前的涨薪机制和年终奖是怎样的吗？

**第三回合：以让步换明确的绩效 / 晋升**
- 模板：
```
我愿意在某些方面做出让步，比如接受一个稍微低一点的起始薪资，
但希望我们能够约定一个明确的绩效考核标准和晋升计划。
```
- 成品：
我愿意在某些方面做出让步，比如接受一个稍微低一点的起始薪资，但希望我们能够约定一个明确的绩效考核标准和晋升计划。

**结束语（通用）**
- 模板：
```
非常感激您提供的机会，并期待我们能够找到一个对双方都满意的解决方案。
```
- 成品：
非常感激您提供的机会，并期待我们能够找到一个对双方都满意的解决方案。

### 4.4 总包拆解对标（别被"福利"带偏月薪）
- **问题**：HR 压价时常拿"我们公积金 12%""有 16 薪""包三餐"来模糊 base。只盯月薪会被带偏。
- **策略**：主动把 offer 拆成"固薪 + 浮动 + 福利"三块，逐项对标市场，再谈缺口。
- 模板：
```
感谢您介绍整体福利。为了对齐，我想把 package 拆开看：
固薪（base × 月数）约[数字]；浮动（绩效/年终）历史兑现比例大概[?]；
福利（公积金基数/比例、补贴、股票）折算约[数字]。
对照我[城市/级别]的市场分位，整体包还差[数字]，能否在[签字费/基数/月数]上补齐？
```
- 成品示例：
感谢您介绍整体福利。为了对齐，我想把 package 拆开看：固薪（base 22k×14）约 30.8 万；浮动（绩效/年终）历史兑现比例大概 70%；福利（公积金 12% 基数、餐补）折算约 2 万。对照我上海中高级的市场分位，整体包还差约 5 万，能否在签字费或基数上补齐？
- **万能防御金句（被压价时）**：
"如果薪资有难度，我理解。但我更关注整体的成长空间和长期回报；不过基于我的过往业绩（[XX 项目 / XX 证书]），期望值确实基于市场分位。请问咱们的薪酬结构里，固浮比和公积金基数是怎样的？"

### 4.5 深挖"可兑现总包"：公积金基数 + 绩效系数陷阱
- **公积金基数确认（差额常被忽略）**：
  - 追问："请问公积金的缴纳基数是按固薪全额、还是按最低基数？比例是多少？"
  - **雷区备注**：很多求职者只谈月薪，忽略双边公积金差额——基数差 10%，年薪实际差 2–3 万，必须前置确认，别等发工资才发现。
- **绩效系数陷阱（"总包含绩效"画饼防御）**：
  - 追问："请问绩效奖金是按部门前 70% 发放，还是全员强制分布（271）？过往两年该岗位实际拿到 1.0 系数（全额绩效）的人员占比大概多少？"
  - **雷区备注**：HR 压价常用"年薪总包含期权/绩效"模糊 base。必须拆清"名义总包"和"历史实际兑现中位数"，别被纸上画饼带偏。
- **升级版万能防御金句（同时锁死四项）**：
"如果薪资有难度我理解。但期望值基于我的过往业绩（[XX 项目 / XX 证书]）和市场分位。请问这个岗位的职级带宽上限、固浮比、公积金基数，以及绩效是强制分布还是按实际贡献发放？我想基于真实可兑现的包来对齐。"

### 备注（谈薪通用）
- 永远给**区间**，不给孤点；先问带宽再报数。
- 用"市场 + 价值"论证，不用"我房租贵 / 想多赚"。
- 用"整体包"视角：base、绩效、年终、签字费、股票、补贴、公积金基数分开谈，别被单项福利模糊整体（见 4.4）。
- 输出话术前先"侧写"HR 心理状态（见 4.0），再选版本；被"福利"带偏时回到总包拆解。
- 谈薪一般是 2 次谈判：第一次明确提出期望薪资 + 理由（自己的能力和市场价值）；第二次若谈不拢，可转非现金补偿或明确涨薪机制。
- **雷区**：先亮底牌说"我只要 X 万"；在没拿到书面 offer 前死磕数字；情绪化；用公司弱点（加班多、福利差）做主要筹码——容易被反感。

## 5. 接受 Offer（确认细节）

**触发**：决定接，需确认入职细节。
**核心**：礼貌确认 + 锁定关键条款，避免口头变卦。

### 模板 A（标准确认版）
```
您好！已确认接受[公司][岗位]的Offer，感谢认可。
我将按要求准备[材料清单]，并于[日期]准时报到。
想再书面确认几点：入职具体时间、汇报线、[薪资构成/试用期]以合同为准无误。
期待加入团队！
```

### 成品示例 A
您好！已确认接受某某科技"高级运营"的 Offer，感谢认可。我将按要求准备身份证、离职证明与学历材料，并于 3 月 15 日准时报到。想再书面确认：入职具体时间、直属汇报线、薪资构成与试用期条款以合同为准无误。期待加入团队！

### 模板 B（收到录用通知后确认资料版）
```
您好，我刚刚收到了您关于[岗位]的录用通知，非常荣幸能够成为[公司]的一员！
我想和您确认一下 offer 里提到的关于入职资料的一些事宜，比如[具体事项]。
```

### 成品示例 B
您好，我刚刚收到了您关于"产品经理"的录用通知，非常荣幸能够成为某某科技的一员！我想和您确认一下 offer 里提到的关于入职资料的一些事宜，比如离职证明是否必须原件、入职具体时间、其他资料带复印件还是原件。

### 备注
- 关键条款书面确认一遍，防"口说无凭"。
- 入职前确认：离职证明要求、入职时间、资料原件/复印件、薪资结构与试用期。
- **雷区**：只回"好的我接了"不锁细节，后续扯皮。

## 6. 拒绝 Offer

**触发**：不去了，需体面拒绝。
**核心**：感谢 + 具体但得体的理由 + 留后路。

### 6.1 已有更好选择
- 模板：
```
尊敬的HR，您好！非常荣幸收到Offer，也感谢认可与薪酬方案。
经慎重考虑，因同时收到更契合我[职业规划/方向]的机会，本次暂无法加入。
对此带来的不便深表歉意，希望未来有机会合作。再次感谢您的支持！
```
- 成品：
尊敬的 HR，您好！非常荣幸收到 Offer，也感谢公司对我的认可及薪酬方案。经慎重考虑，因同时收到更契合我长期职业规划的机会，本次暂无法加入。对此带来的不便深表歉意，希望未来有机会合作。再次感谢您的支持与理解！

### 6.2 薪资 / 方向不符
- 模板：
```
感谢肯定与入职机会。深入了解后，发现该职位与我的[职业规划/薪资预期]存在偏差，
经慎重考虑暂无法接受。望尽快找到更合适人选，也期待未来再合作。感谢全程支持！
```
- 成品：
感谢公司对我的肯定与入职机会。深入了解后，发现该职位与我的职业规划方向存在一定偏差，经慎重考虑暂无法接受。望贵司尽快找到更合适人选，也期待未来再合作。感谢您在整个招聘过程中的支持与理解！

### 6.3 已接 Offer 后临时取消入职
- 模板：
```
[称呼]您好，首先说声抱歉，原本按计划到公司报到的，但因个人原因，经考虑，还是觉得取消入职。
和您之前沟通能够感受到公司的氛围和专业，是我向往的公司，希望以后有机会再合作！
再次感到抱歉！
```
- 成品：
王经理您好，首先说声抱歉，原本按计划到公司报到的，但因个人原因，经考虑，还是觉得取消入职。和您之前沟通能够感受到公司的氛围和专业，是我向往的公司，希望以后有机会再合作！再次感到抱歉！

### 6.4 人脉存款版（推荐替补，留长期好感）——高级打法
- **策略**：真诚告知去向 + 高度认可对方 + 主动推荐 1–2 个符合条件的潜在候选人。HR 最吃这套：你虽没来，却给我介绍了人，下次有好岗位会优先想起你。
- 模板：
```
[称呼]您好，非常感谢贵司的认可。经慎重考虑，我选择了另一条更契合当前阶段的路径，本次无法加入，深表遗憾。
不过我高度认可贵司的[团队/业务]，手头有[1–2位]同样做[岗位/方向]、且正在看机会的靠谱人选，
若您需要，我很乐意私推给您参考。也期待未来有机会再合作，祝招聘顺利！
```
- 成品示例：
李经理您好，非常感谢贵司的认可。经慎重考虑，我选择了另一条更契合当前阶段的路径，本次无法加入，深表遗憾。不过我高度认可贵司的增长团队，手头有两位同样做用户增长、且正在看机会的靠谱人选，若您需要，我很乐意私推给您参考。也期待未来有机会再合作，祝招聘顺利！

### 备注
- 拒绝也要体面，招聘圈很小，HR 可能下次又找你。
- 已接 Offer 再取消是**高风险动作**，尽量在签字前想清楚；必须取消时越早通知越好。
- **6.4 人脉存款版**适用：你真有靠谱人选、且愿意做人情时。空口说"我帮您留意"最虚，带具体人名/方向才有分量。
- **雷区**：骂公司 / 吐槽面试官；放鸽子不回；入职当天消失。

## 7. 挽回此前拒绝的 Offer

**触发**：之前因某原因拒了，现在想回去。
**核心**：说明障碍已消除 + 重申契合。

### 模板
```
[称呼]您好，我是之前应聘[岗位]的[姓名]。
此前很荣幸收到Offer，因[距离/城市]问题当时婉拒。
经慎重考虑，贵司的岗位与文化非常契合我的规划，且我已解决[原障碍]。
请问该岗位是否仍在招聘？若有，我非常愿意继续推进。
```

### 成品示例
李经理您好，我是之前应聘"后端工程师"的王磊。此前很荣幸收到 Offer，因城市调动问题当时婉拒。经慎重考虑，贵司的技术栈与团队文化非常契合我的规划，且我已解决调动问题。请问该岗位是否仍在招聘？若有，我非常愿意继续推进。

### 备注
- 越早联系成功率越高；婉拒后 1–2 周内回头最佳。
- **雷区**：反复横跳消耗 HR 信任。

## 8. 协调 / 改期面试

**触发**：时间冲突，需改期或约时间。
**核心**：主动给 2–3 个候选时段 + 致歉。

### 模板
```
您好！非常期待[日期]的[面试形式]面试。
但因[冲突原因，如已有安排/身体不适]，能否调整至[候选时段1]或[候选时段2]？
给您带来不便十分抱歉，感谢理解！
```

### 成品示例
您好！非常期待周四的腾讯会议面试。但因当天已有既定线下答辩，能否调整至周五上午或下周一？给您带来不便十分抱歉，感谢理解！

### 备注
- 一次给多个可选时间，别只说"我没空你定"。
- **雷区**：临场放鸽子不提前说。

## 9. 解释空窗期 / 离职原因

**触发**：HR 问"为什么离职 / 这段空窗在做什么"。
**核心**：正向叙事，聚焦成长与下一站匹配，不贬前东家。

### 口径 A：业务线战略性裁撤（非个人绩效原因 · 大厂"毕业"主流叙事）
- 模板：
```
我所在的整条[业务线/部门]因集团[战略转向/组织调整]被关停，属于业务裁撤而非个人绩效问题。
在关停前我负责的[XX 项目]ROI 达到[X%]（可数据佐证），这段经历让我更明确要在[领域]深耕。
```
- 成品：
我所在的整条出海业务线因集团战略转向被整体关停，属于业务裁撤而非个人绩效问题。关停前我负责的拉美市场增长项目 ROI 达到 32%，这段经历让我更明确要在用户增长方向深耕，与贵司"用户增长运营"高度契合。

### 口径 B：未续约 / 拿 N+1 主动转型（把被动变主动投资）
- 模板：
```
[合同到期/公司转型]双方未续约，我利用拿到的[N+1/空窗期]系统补习了[XX 新技能/考取 XX 证书]，
正好精准匹配贵司现在的[XX 岗位]要求。空窗期是主动的能力投资，不是空白。
```
- 成品：
合同到期后公司面临转型，双方未续约。我利用拿到的 N+1 空窗期系统补习了 SQL 与增长方法论、考取了 Google Analytics 证书，正好精准匹配贵司"用户增长运营"的岗位要求。空窗期对我而言是主动的能力投资，不是空白。

### 备注
- **区分口径是关键**：HR 忌惮的是"因绩效末位被裁"，不忌惮"业务线裁撤"。口径 A 必须点明"整条线裁撤 + 数据佐证"，把"被毕业"和"我不行"切割开。
- 口径 B 把"被动离职"转化为"主动能力投资"，用新技能 / 证书直接对齐目标岗位，化被动为主动。
- 不吐槽前公司 / 领导；把空窗包装为"蓄力期"。
- **雷区**：模糊说"公司优化了我"（易被解读为绩效问题）；说"原公司太坑""领导傻"——直接减分；拿不出任何空窗期产出的"纯休息"叙事。

## 10. 反问面试官 / 面试前必问

**触发**：面试结尾 HR / 面试官问"你还有什么想问的吗"；或面试前想确认岗位基础信息。
**核心**：按面试官身份挑问题——问 HR 问制度/流程，问主管问业务/成长；面试前把 JD 上不清楚、影响决策的信息先问清。

### 面试结尾可问清单（按面试官身份选 1–2 个）

**问 HR（人事 / 行政 / 制度类）**
- 这个岗位还需要几轮面试？大概什么时候能通知结果？
- 上下班时间、周末单双休、节假日放假情况是怎样的？
- 薪资构成是怎样的？底薪多少？绩效怎么算？有无餐补 / 车补 / 房补？五险一金比例？
- 是否加班？加班工资怎么算？年假怎么算？
- 试用期多久？转正时间和标准是什么？
- 该职位所在部门的组织架构是怎样的？我的直属汇报对象是谁？
- 公司对着装 / 工装有要求吗？

**问部门主管 / 业务面试官（岗位 / 成长类）**
- 这个岗位的具体工作内容是什么？我主要负责哪块？团队大概多少人？
- 公司 / 团队的晋升机制是怎样的？
- 入职后有没有相关技能培训？有哪些是我需要着重了解和学习的？
- 您希望我在这个岗位上发挥怎样的价值？做到什么程度算合格或优秀？
- 公司每年是否有调薪机会？调薪机制是怎样的？
- 这个岗位未来半年最关键的 1–2 个目标是什么？
- 团队目前的技术 / 业务成熟度处在哪个阶段？
- 这个职位是新增还是替补？团队接下来的业务重点？
- 问点你刚才面试中产生的、具体工作上的疑问。

### 面试前也可问 HR 的问题
- **"方便了解一下薪资结构吗？"**——问清无责底薪、绩效及考核标准、提成、奖金、补贴等，确保能接受最低薪资再面试。
- **"请问试用期是多久呢？"**——同时问转正标准、试用期薪资。《劳动合同法》规定：3 个月以上不满 1 年，试用期≤1 个月；1 年以上不满 3 年，试用期≤2 个月；3 年以上 / 无固定期限，试用期≤6 个月。
- **"方便了解一下工作时间吗？"**——正常工作时间、休息、加班情况。
- **"这个岗位的主要工作内容是什么？"**——确认 JD 上写不清楚、但实际影响你去不去的关键职责。

### 10-B AI 面试 / 异步录播视频面试（One-way Interview）应试策略
**触发**：初筛环节遇到 HireVue、深言科技等 AI 工具，或要求录制视频作答（无真人面试官）。这与"反问面试官"不同——你面对的是算法评分，没有反问对象。
**核心**：前 3 分钟定生死；用 JD 关键词喂给算法；结尾埋钩子争取真人面。

- **肢体与眼神**：看镜头而非屏幕里的人脸（算法按"眼神接触"打分）；环境安静、光线正面；语速稳。
- **黄金前 3 分钟**：把岗位 JD 前 3 项核心能力的关键词脱口而出（如"用户增长、数据驱动、从 0 到 1"），让算法抓取匹配度。
- **结尾留钩子（为进真人面埋伏笔）**：
  - 模板：`关于刚才提到的[XX 项目]，我还有更落地的数据细节，非常期待能与业务负责人进行深度双向交流。`
  - 成品：关于刚才提到的拉美市场增长项目，我还有更落地的 ROI 拆解与复盘数据，非常期待能与业务负责人进行深度双向交流。

### 反向背调：试探隐性加班与内卷文化（钝感力测试）
**触发**：年轻人极看重 WLB 与情绪价值，但直接问"加班多吗"HR 会套路答"有项目时多"。用不敏感的词套出真实节奏。
**可问（挑 1–2 个，观察对方微表情比听回答更重要）**：
- "咱们团队晚上 8 点后、以及周末的钉钉 / 飞书消息回复率大概在什么水平？大家通常几点离开工位？"
- "如果用一个词形容团队工作风格，是'极致快节奏'还是'稳扎稳打细水长流'？"
- "团队最近一次集体赶项目是什么时候？那段时间大致的节奏是怎样的？"

### 面试前 / 后的"避雷"核验（社交平台交叉验证）
- 面试前 / 后，可上脉脉匿名区、小红书、看准网搜"公司名 + 加班 / 裁员 / 画饼"关键词，交叉验证 HR 承诺的福利、晋升真实性。
- 若发现 HR 口嗨（虚假承诺 / 美化加班），后续谈薪时**适当调高心理预期底线**，别被"我们文化很好"带偏。
- 注意甄别水军与极端个案，不凭一条帖子下定论。

### 备注
- 反问体现你认真思考、真的想来，而非只关心钱。
- HR / 面试官问"你还有什么问题"的潜台词：考察三件事——
  - **求职动机**：你是不是真的很想来？
  - **关注点高度**：你只关心自己待遇，还是关心团队 / 业务？
  - **思考能力**：你是否对岗位有深入思考？
- 不要照着清单全问，挑 1–2 个最贴合岗位和你真实关心的问题。
- **反向背调（见上文"钝感力测试"）**：用不敏感词套真实节奏，比直接问"加班多吗"更能拿到真话；"避雷"核验见上方社交平台交叉验证小节。
- **雷区**：一上来问"几点下班""加班多吗"（可委婉问工作方式）；问面试中已经问过的问题；直接说"没有问题"。

## 11. 反诈拒坑（免费内推 / 押金 / 培训贷）

**触发**：遇到"交押金""付费内推""先培训后入职""押证件"。
**核心**：正规招聘不收费；礼貌但坚定拒绝，必要时拉黑。

### 识别红线
- 任何以"培训费 / 押金 / 保证金 / 体检费"名义收费 → 违法。
- "付费内推""保 offer" → 大概率为骗局。
- 扣押身份证 / 毕业证原件 → 违法，可拒。
- 面试前要求转账 / 买课 → 直接拉黑。

### 得体拒绝模板
```
感谢您的联系。根据相关规定，正规招聘不收取任何费用，
也不扣押证件，因此我无法接受该安排，望理解。祝招聘顺利。
```
- 成品：
感谢您的联系。根据相关规定，正规招聘不向求职者收取任何费用，也不扣押个人证件，因此我无法接受该安排，望理解。祝招聘顺利。

### 备注
- 遇到红线不必客气，保护自己是第一优先级。
- 可保留证据向平台举报。

## 12. 背调 / 薪资证明授权

**触发**：HR 要背调联系人、薪资流水。
**核心**：配合但知边界，敏感信息可脱敏。

### 模板
```
可以的，我配合背景调查。
现提供[前主管/同事]作为证明人（[姓名/关系/联系方式]）。
薪资方面我可提供[税前年薪区间/offer截图]，涉及具体流水涉及隐私，
看是否可用[个税APP记录/脱敏截图]替代。
```

### 成品示例
可以的，我配合背景调查。现提供前主管陈先生作为证明人（关系：直属上级，电话：1xx）。薪资方面我可提供税前年薪区间与 offer 截图；具体银行流水涉及隐私，能否用个税 APP 记录或脱敏截图替代？

### 备注
- 背调提前和证明人打好招呼。
- **雷区**：造假薪资流水——一旦背调出问题直接出局且影响信誉。

## 13. 意向城市 / relocation 澄清（HR 指出城市不符）

**触发**：HR 说"我看你意向城市不是 XX""你写的是外地，能来我们这吗"。
**核心**：先分清是"填错"还是"真不想来"，再给准话；能 relocate 就主动亮底牌，不能就体面退出。

### 分支 A：愿意去 / 可接受 relocate（最常见）
- 模板：
```
谢谢提醒！我简历意向城市当时填的是[原城市]，但我对贵司在[目标城市]的岗位很感兴趣，
relocate 完全没问题 / 我可以接受工作地调动。
如有需要，我也可以提前到岗熟悉环境。期待进一步沟通！
```
- 成品：
谢谢提醒！我简历意向城市当时填的是上海，但我对贵司在杭州的岗位很感兴趣，relocate 完全没问题，我可以接受工作地调动。如有需要，我也可以提前到岗熟悉环境。期待进一步沟通！

### 分支 B：填错了，实际就是这个城市
- 模板：
```
谢谢指出！意向城市那栏是我当时填错了，我的目标城市其实就是[目标城市]。
已更新，请以[目标城市]为准，期待后续流程！
```
- 成品：
谢谢指出！意向城市那栏是我当时填错了，我的目标城市其实就是杭州。已更新，请以杭州为准，期待后续流程！

### 分支 C：确实不想去 / 想远程，体面说明
- 模板：
```
感谢提醒。我的意向城市确实填的是[原城市]，目前更倾向[原城市/远程]发展，
因此这个岗位可能不太匹配我的规划。还是非常感谢您的联系，祝招聘顺利！
```
- 成品：
感谢提醒。我的意向城市确实填的是成都，目前更倾向留在本地发展，因此这个岗位可能不太匹配我的规划。还是非常感谢您的联系，祝招聘顺利！

### 备注
- 先确认 HR 指的是"工作地"还是把你"现居地 / 籍贯"误读了——有时是误会，不必急着改口。
- 能 relocate 就直接说"完全没问题"并主动提"可提前到岗"，是加分项；含糊说"都可以"反而让 HR 不敢推进。
- **雷区**：为拿面试撒谎说"一直想来"，背调或入职前露馅直接出局；或明明不想去还吊着 HR。

## 14. 请求面试 / 约面试

**触发**：和 HR 初步沟通后，想主动推进到面试环节。
**核心**：表达意向明确 + 主动给候选时间，降低 HR 决策成本。

### 模板
```
[称呼]您好，我这边暂时没什么疑问了，咱们互相也了解得差不多了，
我对贵公司的[岗位]也很有意向，想问问什么时候方便约个面试呢？[候选时间]可以吗？
```

### 成品示例
王经理您好，我这边暂时没什么疑问了，咱们互相也了解得差不多了，我对贵公司的"产品经理"岗位也很有意向，想问问什么时候方便约个面试呢？周三下午三点可以吗？

### 备注
- 主动给 1–2 个具体时间段，方便 HR 直接确认或调整。
- 若 HR 已读但未发面试邀请，这条可以直接推进。
- **雷区**：只问"什么时候面试"却不给时间，增加来回成本。

## 15. Offer 暂缓答复（想再拖拖 / 仍在考虑）

**触发**：收到 offer 但不急着接，想等其它面试结果或再评估。
**核心**：表达感谢 + 说明情况 + 明确最晚回复时间；体面争取缓冲期。

### 分支 A：想拖一拖（有其他面试在流程中 / 需要时间决策）
- 模板：
```
[称呼]您好，非常高兴能收到[公司][岗位]的 offer，感谢公司和各位面试官对我的肯定。
但由于[原因，如个人事务/职业规划梳理/还有其他面试在流程中]，我目前还需要一些时间处理/考虑。
个人处理完毕/慎重考虑后，最晚会在[日期]前给到您明确的回复。您看这样可以吗？再次感谢！
```
- 成品：
王经理您好，非常高兴能收到某某科技"产品经理"的 offer，感谢公司和各位面试官对我的肯定。但由于我目前还有其他面试在流程中，同时也想对个人职业规划再做一次梳理，所以还需要一点时间。慎重考虑后，最晚会在下周五前给到您明确的回复。您看这样可以吗？再次感谢！

### 分支 B：仍在考虑中（对 offer 内容有疑问）
- 模板：
```
[称呼]您好，非常荣幸能收到[公司][岗位]的 offer，感谢贵公司给我提供的这次机会。
对于 offer 中的[某项内容，如薪资结构/汇报线/工作内容]，我仍不是很清楚，
想更详细地了解一下，明确清楚后我再给您确定答复。盼回复，祝工作顺利，感谢！
```
- 成品：
王经理您好，非常荣幸能收到某某科技"产品经理"的 offer，感谢贵公司给我提供的这次机会。对于 offer 中的薪资结构与绩效考核标准，我仍不是很清楚，想更详细地了解一下，明确清楚后我再给您确定答复。盼回复，祝工作顺利，感谢！

### 备注
- 拖时间要给**明确 deadline**，别让 HR 无限等；一般争取 3–5 个工作日较合理。
- 若因为等其他 offer，不必明说"我在等更好的"，用"个人事务 / 职业规划梳理"带过。
- **雷区**：超过 deadline 还不回复；用"还在考虑"做借口实际已经不想去了；承诺了回复时间又放鸽子。

## 16. 面试后感谢信 / 跟进信（面完 24 小时内）

**触发**：面试结束，想加深印象、补救小失误、或表达强意向。
**核心**：24 小时内发；点到具体交流细节显真诚；可补一句面试中没说清的亮点；别写成群发。

### 模板 A（标准感谢版）
```
[称呼]您好，今天和您聊[岗位]很受启发，尤其关于[具体话题，如"你们提到的复购打法"]让我很有共鸣。
再次感谢您的时间与分享，也期待能有机会加入[公司]、把[我的某能力]落到实处。如有进一步流程，随时联系我，谢谢！
```

### 成品示例 A
王经理您好，今天和您聊"用户增长运营"很受启发，尤其关于你们提到的"内容驱动复购"打法让我很有共鸣。再次感谢您的时间与分享，也期待能有机会加入贵司、把我过去搭会员体系的经验落到实处。如有进一步流程，随时联系我，谢谢！

### 模板 B（补救面试失误版）
```
[称呼]您好，关于面试中[某个问题]我当时回答不够完整，补充一下：
[更优答案/数据佐证]。这次交流让我更确定[岗位]很适合我，期待后续！
```

### 成品示例 B
王经理您好，关于面试中"如何衡量增长"那题我当时答得不够完整，补充一点：我常用的北极星指标是复购率而非单纯 GMV，因为前者更反映留存质量——这点和贵司思路一致。这次交流让我更确定这个岗位很适合我，期待后续！

### 备注
- **黄金窗口**：面试后 24 小时内；超过 48 小时效果锐减。
- 提到"具体话题"比"感谢您的时间"真诚十倍，证明你真在听。
- **渠道**：邮件优先（正式、可留痕）；若全程在微信沟通，微信发也可，但语气仍要正式。
- **雷区**：群发同款"感谢信"；过度恭维；借感谢信反复追问结果。

## 17. 微信 / 电话初次添加与沟通礼仪（国内招聘高频渠道）

**触发**：HR 主动加你微信 / 要电话，或你主动加 HR。
**核心**：添加即建立职业形象；第一句决定后续观感；渠道有别于邮件。

### 添加好友
- **备注名模板**：`[姓名]-应聘[岗位]-[来源平台]`，如"张华-应聘产品经理-Boss直聘"。HR 通过时一眼知道你是谁。
- 验证消息：`[称呼]您好，我是应聘[岗位]的[姓名]，之前在[平台]和您沟通，方便加您微信进一步对接，谢谢！`

### 通过后第一句（自报家门 + 不空手）
- 模板：`[称呼]您好，我是[姓名]，应聘[岗位]，很高兴加上您。我的简历和作品集已附上（或"稍后发您"），方便时请您查收，谢谢！`
- **不要**：只发"您好""在吗"然后消失；一通过就甩长语音；连发"在吗在吗"。

### 微信沟通纪律
- 工作时间发（10:30 前后 / 15:00 后）；非紧急别在 21:00 后发。
- 长内容分段发，别刷屏；重要约定（面试时间、offer 要点）最后用一句话总结确认。
- **雷区**：发 60 秒以上长语音；发表情包刷屏；把微信当邮件写小作文；已读不回 HR（双向奔赴，别只要求 HR 回你）。

### 电话礼仪
- 接起先自报家门："您好，我是[姓名]，应聘[岗位]的，现在方便通话吗？"
- 不确定对方是否方便，先问"现在方便说话吗"，别一上来长篇。
- 挂前复述关键结论（时间 / 下一步），避免误解。

### 备注
- 微信是"轻量高频"渠道，适合面试协调、进度轻催；**薪资 / 背调 / 录用确认仍建议邮件留痕**（见总原则渠道分级）。
- 一次把"备注名 + 验证语 + 通过后首句"配齐，HR 对你的职业感评分直接拉满。

## 18. HC 冻结 / 口头 Offer 撤回（市场寒冬应对）

**触发**：面试通过但被告知"岗位暂缓 / 业务调整 / HC 冻结"；或口头 Offer 后迟迟不下正式 offer、甚至被鸽。
**核心**：不质问、不卑微；把诉求转化为"保持热联 + 问解冻时间线 + 争取同集团内推"。

### 分支 A：HR 说"岗位暂缓 / 业务调整"
- 模板：
```
理解公司的战略调整，完全没问题。
请问这个岗位是彻底取消，还是暂时封存？如果后续重启，我希望能被优先考虑；
如果集团内有职责相近的其他 BU / 岗位机会，也麻烦您帮我留意或内推，感谢！
```
- 成品：
理解公司的战略调整，完全没问题。请问"用户增长运营"这个岗位是彻底取消，还是暂时封存？如果后续重启，我希望能被优先考虑；如果集团内有职责相近的其他 BU 或城市的机会，也麻烦您帮我留意或内推，感谢！

### 分支 B：口头 Offer 后无下文 / 被鸽
- 模板：
```
[称呼]您好，之前咱们沟通[岗位]的 offer 很顺畅，我也已婉拒了其他机会。
想确认一下目前的进展：是流程上还需时间，还是岗位 / HC 有调整？
如果是后者，我完全理解，也希望能保持联系；若有重启或相近机会，盼您优先想起我。
```
- 成品：
李经理您好，之前咱们沟通"高级运营"的 offer 很顺畅，我也已婉拒了其他机会、在等贵司。想确认一下目前的进展：是流程上还需时间，还是岗位 / HC 有调整？如果是后者，我完全理解，也希望能保持联系；若有重启或相近机会，盼您优先想起我。

### 备注
- **关键心态**：HC 冻结 / 口头 offer 撤回是市场与组织行为，不是你不够好，别内耗、别质问。
- 把"追问结果"转化为"争取内推 + 保持热联"——即使本岗没了，同集团其他 BU 可能仍有 HC，HR 也愿意帮"配合度高、不闹事"的候选人。
- 问清"彻底取消 vs 暂时封存"很重要：前者及时止损去别家，后者留个钩子等重启。
- **雷区**：情绪化质问"你们为什么鸽我"；口头 offer 后立刻推掉所有其他机会不留后路（口头≠书面，拿到盖章 offer 前别断后路）；无限等待不跟进。

## 19. 被问"你当前薪资多少"——保密与重定向（谈薪锚定战核心）

**触发**：HR 问"你现在的薪资是多少""能看下工资流水/当前 offer 吗""目前年薪多少"。这是 HR 最常用的**锚定压价**开局——一旦你报出偏低当前数，后续期望会被锁死在它附近。
**核心**：谈薪阶段**不暴露精确当前数**；把问题重定向为"我的期望（基于市场+价值）"；仅在进入背调/已出书面 offer 时才做有限披露。

### 分支 A：标准重定向（最常用 · 谈薪阶段）
- 模板：
```
感谢您想了解背景。出于薪资保密原则，我更习惯基于岗位的市场分位和我的可量化产出直接对齐期望，
而非以"当前数字"为基准。结合[城市/级别]市场，我的期望总价在[下限]–[上限]万，
这个数字对应[能力/成果，如"3 年 SaaS 增长、主导 2 次破百万裂变"]。
```
- 成品：
感谢您想了解背景。出于薪资保密原则，我更习惯基于岗位的市场分位和我的可量化产出直接对齐期望，而非以当前数字为基准。结合上海中高级市场，我的期望总价在 35–42 万，这个数字对应我 3 年 SaaS 增长、主导过 2 次破百万裂变项目的积累。

### 分支 B：对方坚持要数字（实为背调材料需求）
- 模板：
```
理解需要材料。薪资流水涉及个人隐私，我可在进入正式背调阶段提供
[税前年薪区间 / 个税 APP 记录 / 脱敏截图]；但谈薪阶段我希望以"期望 + 市场"为基准，
避免锚定偏差影响双方判断。
```
- 成品：
理解需要材料。薪资流水涉及个人隐私，我可在进入正式背调阶段提供税前年薪区间与个税 APP 记录；但谈薪阶段我希望以"期望 + 市场"为基准，避免锚定偏差影响双方判断。

### 分支 C：已出书面 offer、对方需对标（有限披露）
- 模板：
```
既然已进入实质阶段，我可以透露参考区间：我当前 base 约[X]k×[月数]，绩效历史兑现约[Y]%。
我的期望是基于此再[+Z%]的市场对标，而非简单持平——这样对双方都透明。
```
- 成品：
既然已进入实质阶段，我可以透露参考区间：我当前 base 约 22k×14，绩效历史兑现约 70%。我的期望是基于此再上浮约 15% 的市场对标，而非简单持平——这样对双方都透明。

### 备注
- **核心策略**：把"你现在的薪资"问题，**换成"我的期望"**。锚点从"你过去可能偏低的薪资"转为"市场价值"，这是谈薪最重要的一个转身。
- 区分两类要数场景：**背调要流水**（可给脱敏/区间，见场景 12）→ 合理；**谈薪问当前**（不给精确数）→ 重定向。两者目的不同，应对不同。
- **雷区**：一上来报精确当前数（被锚死在低处，后面怎么谈都亏）；虚报当前薪资博高（背调穿帮直接出局）；用"我现在很低所以好谈"卖惨（显得没底气，反被压）。
- 与场景 4 联动：重定向后立即接 4.1 的"报期望区间"或 4.4 的"总包拆解"，不要只挡不进。

## 20. 多 Offer 管理 / 向 HR 表态优先级

**触发**：手握 2 个及以上 offer / 流程，需向某家 HR 表达强意向以推动流程或争取条款，同时不暴露全部底牌。
**核心**：用"强意向 + 明确时间窗口"制造合理推力，而非"我有更好 offer 你来抢我"（后者招反感、像抬价筹码）。

### 分支 A：向目标 HR 表达优先级 + 催决策
- 模板：
```
[称呼]您好，贵司是我目前最优先的选择，几轮沟通下来也很契合。
我手上另有一个流程也进入了终面/已出 offer，对方希望我[日期]前确认。
但我想先把贵司走完——能否麻烦您帮忙确认下本周内能否有进一步进展？
```
- 成品：
王经理您好，贵司是我目前最优先的选择，几轮沟通下来也很契合。我手上另有一个流程也进入了终面，对方希望我下周五前确认。但我想先把贵司走完——能否麻烦您帮忙确认下本周内能否有进一步进展？

### 分支 B：用选择权争取目标家更好条款
- 模板：
```
我很想来贵司。坦白说另一家给了[级别/总包]的方案，但我更看好这边的[业务/成长/平台]。
如果贵司能在[签字费 / 某补贴 / 职级]上再靠拢一点，我可以今天就确认。
```
- 成品：
我很想来贵司。坦白说另一家给了 38 万总包的方案，但我更看好这边的国际化业务与成长空间。如果贵司能在签字费或职级上再靠拢一点，我可以今天就确认。

### 分支 C：婉拒其中一个、留人脉（见场景 6.4 人脉存款版）
- 直接复用场景 6.4：真诚告知去向 + 高度认可 + 主动推荐替补人选。

### 备注
- 说"最优先"给足对方面子，说"另有一个流程"制造**合理时间压力**（不是威胁），但不说"谁给多少"——避免被当成抬价工具。
- **雷区**：同时和多家 HR 说"你们是我第一选择"（被识破信誉破产）；用 Offer A 的精确数字硬压 Offer B 且语气像威胁；为多拿一点把表态优先级说成谎言。

## 21. 猎头沟通（外猎 / 内推渠道）

**触发**：猎头主动联系、推岗位、转述薪资、或你通过猎头找机会。
**核心**：猎头是**渠道不是雇主**；目标是对齐岗位匹配 + 薪资预期 + 流程节奏，让他帮你精准推，而不是被他带节奏催接。

### 分支 A：猎头来撩，先评估岗位基本面
- 模板：
```
谢谢[猎头名]推荐。方便先同步下这个岗位的[薪资范围 / 汇报线 / 业务阶段 / 客户公司名]吗？
我对[方向]有兴趣，但希望先确认基本面是否匹配，避免浪费彼此时间。
```
- 成品：
谢谢 Kevin 推荐。方便先同步下这个岗位的薪资范围、汇报线和客户公司名吗？我对用户增长方向有兴趣，但希望先确认基本面是否匹配，避免浪费彼此时间。

### 分支 B：通过猎头谈薪（让猎头先探带宽）
- 模板：
```
基于我的[经验 / 成果]，期望总价[区间]万。麻烦您先和客户端对齐下预算带宽，
如果差距在[10%]内我们可以细谈；差距过大我建议暂不推，省得来回。
```
- 成品：
基于我 3 年 SaaS 增长经验，期望总价 35–42 万。麻烦您先和客户端对齐下预算带宽，如果差距在 10% 内我们可以细谈；差距过大我建议暂不推，省得来回。

### 分支 C：猎头催你接 / 压价，守住节奏
- 模板：
```
理解时间紧。但薪资和平台我都还想再对齐一下，不想为了快而接错。
如果本周内能给出[某条件]，我可以推进；否则我先看别的。
```
- 成品：
理解时间紧。但薪资和平台我都还想再对齐一下，不想为了快而接错。如果本周内能给出签字费方案，我可以推进；否则我先看别的。

### 备注
- 猎头赚**成单佣金**，有动力帮你谈、也会催你接——决策权始终在你自己手里，别被带节奏。
- 先问 JD 三要素（薪资区间 / 汇报线 / 业务阶段）再决定是否推进，别海接。
- **雷区**：把猎头当 HR 倾吐隐私；对猎头虚报当前薪资（他会直接转给客户方做背调）；同时让多家猎头推同一岗位（撞车尴尬）。

## 22. 口头 / 书面 Offer 条款核对清单（接之前锁死）

**触发**：收到口头或书面 offer，准备接之前需逐项确认关键条款。
**核心**：接之前把"模糊点"一次性书面问清，避免入职后扯皮；**口头 offer 必须转书面再接**。

### 模板（书面锁定版）
```
感谢 offer！为确认无误，想书面锁定以下几点：
① 入职日期与试用期（时长 / 试用期薪资 / 转正标准）；
② 薪资结构（base×月数、绩效比例与历史兑现中位数、签字费 / 补贴、公积金基数与比例）；
③ 汇报线与岗位职级；
④ 股票 / 期权（如有）的授予节奏与归属期（vesting）；
⑤ 违约责任（如服务期 / 培训协议绑定）。
以上以劳动合同为准，盼书面确认，谢谢！
```

### 备注
- 场景 4.4 / 4.5 的薪资拆解（固浮比、公积金基数、绩效强制分布）应**落到此处逐项书面确认**，不要只在口头谈。
- 口头承诺的"晋升 / 调薪"不是既定事实，必须写进 offer 或合同才作数。
- **雷区**：只口头接了不锁条款；忽略"服务期 / 违约金"绑定；把"口头画饼"当既定福利。
